# 决策树剪枝实验说明

决策树页面新增了一个与原有视觉风格一致的剪枝实验台，用于直观比较模型复杂度与泛化能力。原有数据生成、树结构画布、性能指标、样本预测和决策路径功能保持不变。

## 支持的策略

| 策略 | 作用 | 主要参数 |
| --- | --- | --- |
| 未剪枝 | 让树充分生长，作为高复杂度基线 | 无 |
| 预剪枝 | 在训练过程中阻止收益较低或样本过少的分裂 | `max_depth`、`min_samples_split`、`min_samples_leaf`、`max_leaf_nodes`、`min_impurity_decrease` |
| 自动后剪枝 | 先生成完整树，再通过交叉验证选择 `ccp_alpha` | `cv_folds` |
| 手动后剪枝 | 使用指定的代价复杂度系数删除弱分支 | `ccp_alpha` |

自动后剪枝只使用训练集进行参数选择。它采用 one-standard-error 规则：先找到交叉验证准确率最高的候选，再从统计表现接近最优的候选中选择结构更简单的树。测试集只用于最终效果展示，不参与调参。

阈值为最佳候选的交叉验证均值减去其标准误，标准误使用各折准确率的样本标准差除以折数的平方根。剪枝路径最多抽取 24 个候选，手动模式会额外纳入用户指定的精确 alpha，因此最多 25 个点。图中曲线是候选采样展示，不代表所有可能的剪枝结果。

交叉验证折数会按训练集中最少类别的样本数自动缩小。若某类别不足 2 个样本，则不进行分层交叉验证；自动模式保留 alpha=0，并展示原因，而不是生成误导性的验证分数。

## 页面展示

训练完成后页面会同时展示：

- 未剪枝、预剪枝、后剪枝三种模型的训练准确率与测试准确率；
- 训练/测试准确率差距，用于辅助判断过拟合；
- 树深度、叶节点数和总节点数；
- 相对未剪枝基线的节点精简比例、准确率变化和泛化差距变化；
- `ccp_alpha` 与交叉验证/测试准确率的剪枝路径曲线；
- 最终选中模型的完整树结构和样本决策路径。

### 灰色圆圈剪枝位置对照图

2026-10-28 增加并修正“剪枝位置对照图”，位于剪枝效果分析区的指标下方。主图必须完整显示当前模型的全部节点，不能只显示与基线匹配成功的节点。展示分为两种模式：

- **同图灰圈对照**：当前树是未剪枝基线的严格子树时，保留基线布局，彩色节点对应完整当前模型，灰圈补充被移除的后代。
- **前后双图对照**：预剪枝改变分裂规则时，上图单独绘制完整当前模型，下图单独展示完整基线。不能把基线中无法对应的橙色节点当作当前模型节点，也不能把净减少数量直接解释成同样数量的灰圈。

- 主图中紫色圆圈：当前模型内部节点；绿色圆圈：当前模型叶节点。
- 绿色圆圈加紫色外环：剪枝位置。该节点本身保留为当前模型的叶节点，其后代才被剪除。
- 灰色圆圈和灰色虚线：后剪枝中已剪除的后代。预剪枝模式下标为“未继续生长”，表示完整基线中对应的后续结构，并非先长出来再删除。
- 橙色节点只出现在独立的基线图中：表示预剪枝造成分裂规则改变，不能与最终模型逐节点对应的旧区域。这些节点不会被误标成已剪除，也不会冒充主图中的实际节点。

同图模式提供“显示灰色分支”开关，隐藏灰圈不会移动其他节点。主图提供放大/缩小、完整视图、清晰视图及节点详情，基线图提供独立的全貌与清晰视图。默认缩放不低于 80%，大树通过滚动查看，避免默认缩成难以辨认的密集小点；“完整视图”才会按宽高缩小至全貌。**F 编号是当前模型节点，B 编号是基线节点**；点击或使用 Tab/Enter 选中节点可查看对应模型的真实规则、样本量、不纯度和状态。

后端返回 `pruning_info.tree_comparison`：`nodes` 是带匹配状态的完整基线，`selected_nodes` 是直接从最终 sklearn 模型导出的完整树，与匹配是否成功无关。匹配依据是共同决策路径与分裂规则，**不是会重新编号的节点 ID**。前端按实际 DOM 中的 F 节点校验数量、唯一性和 ID 集合，显示“29 / 29 个节点已绘制”这样的核对结果。若完整模型数据缺失或绘图数量不一致，会停止显示而不是拿不完整基线冒充最终树。严格子树关系下灰圈数等于节点净减少数；非严格子树不能作此推断。

用户反馈回归案例：鸢尾花 150 条、2D 模式、最大特征数 `sqrt`、最大深度 5、最大叶节点 15、划分种子 42。基线为 91 节点，最终模型为 29 节点，但只有 4 个节点与基线直接对应。修正后的主图必须画出全部 F0–F28 共 29 个节点和 28 条实际父子连线；下图另画 91 个基线节点。该案例已纳入自动化测试和真实浏览器检查。

这张图仅做教学对照，不参与模型预测。下方原有树结构、全屏查看、样本预测和决策路径高亮仍使用最终模型，不包含灰色节点。

演示步骤：选择鸢尾花、150 个样本、完整特征模式、最大特征数“所有特征”，生成数据；选择“手动后剪枝”，输入 `ccp_alpha=0.02`，构建决策树。向下查看“剪枝位置对照图”，切换灰色分支开关进行展示。选择“未剪枝”时不出现灰色节点，`ccp_alpha=0` 时也可能完全不剪枝，这是正常情况。

“准确率变化”和“泛化差距变化”使用**百分点**，不是相对增长百分比。例如测试准确率从 80% 变成 70%，变化是 -10 个百分点。泛化差距定义为训练准确率与测试准确率差值的绝对值，变化为负表示差距缩小。节点精简比例则使用百分比。

剪枝不保证准确率提高。剪枝过强可能导致欠拟合；需要结合测试准确率、模型复杂度和交叉验证表现判断。测试集指标适合最终评价，不应反复据此挑选参数。

## API 参数示例

```json
{
  "session_key": "full_iris_150",
  "params": {
    "criterion": "gini",
    "pruning_method": "post_auto",
    "cv_folds": 5,
    "test_size": 0.2,
    "random_state": 42
  }
}
```

`pruning_method` 可取 `none`、`pre`、`post_auto`、`post_manual`。训练响应的 `results.pruning_info` 包含候选路径、策略对比、最终复杂度和剪枝说明。
